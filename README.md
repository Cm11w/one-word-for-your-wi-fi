## The word

> Ghosting

Like a date who stops replying mid-conversation, the Wi-Fi is there one second and gone the next — no explanation, no goodbye.

## How it works

`main.ts` writes the word above to `/output/entry.txt` — one word, under 20 characters — after checking it against the competition gate (1–20 characters, not only whitespace, exactly one word).

Run it with Node 22 or later:

```sh
node main.ts
```
